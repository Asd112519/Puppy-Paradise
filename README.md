# The Puppy Paradise 🐶

The Puppy Paradise is a delightful and interactive web application dedicated to dog lovers. It features a collection of fun mini-games, comprehensive dog care guides, breed information, and adoption resources.

## 🎮 Game Zone

Challenge yourself with our collection of dog-themed mini-games:

- **Dice Roll Race** 🎲: A competitive game where you race to score 100 points. Play against "Penny" the AI or a friend in local multiplayer mode!
- **Block Blast** 🧩: A classic puzzle game where you arrange colorful blocks on an 8x8 grid.
- **Fetch!** 🎾: Test your reflexes by catching balls before they leave the screen.
- **Penny's Memory Match** 🧠: A memory card game with progressive levels.

## 📘 Features

- **Breed Explorer**: Detailed information about various dog breeds.
- **Dog Care Guide**: Essential tips and advice for taking care of your furry friend.
- **Adoption Center**: Learn about adoption and find your perfect match.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop devices.
- **Dark Mode**: Toggle between light and dark themes for comfortable viewing.

## 🛠️ Tech Stack

- **Frontend**: React, TypeScript, Vite
- **Styling**: Tailwind CSS, shadcn/ui
- **Icons**: Lucide React
- **Animation**: Framer Motion
- **Backend**: Express (Node.js)
- **Routing**: React Router

## 🚀 Getting Started

1.  **Clone the repository**
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Start the development server**:
    ```bash
    npm run dev
    ```
4.  **Open your browser** and navigate to the local server address (usually `http://localhost:5000` or `http://0.0.0.0:5000`).
